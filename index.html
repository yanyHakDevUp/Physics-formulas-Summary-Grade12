សង្ខេបរូបមន្តរូបវិទ្យា ថ្នាក់ទី១២

Summary of Physics Formulas Grade 12

១៣ មេរៀន
🌡️

រមេរៀនទី ១: ទ្រឹស្ដីគីនេទិចនៃឧស្ម័ន

សមីការឧស្ម័នឥតប្រែប្រួល
PV = nRT
P = សម្ពាធ
V = ទំហំ
n = ចំនួនម៉ូល
R = ថេរឧស្ម័ន
T = សីតុណ្ហភាព
ចំនួនម៉ូលេគុលសរុប
N = nN_A
ដែល N_A = 6.022 × 10²³ mol⁻¹ (លេខអាវ៉ូហ្គាដ្រូ)
ម៉ាស់ម៉ូល
M = m/n
ចំនួនម៉ូល
n = N/N_A = m/M
ថាមពលគីនេទិច
E_k = (3/2)kT
(មធ្យមសម្រាប់ម៉ូលេគុលមួយ)
E_total = (3/2)NkT = (3/2)nRT
(សរុប)
ល្បឿន RMS
v_rms = √(3kT/m) = √(3RT/M)
សម្ពាធដោយឧស្ម័ន
P = (1/3)ρv_rms²
(ការប៉ះទង្គិចអេឡាស្ទិក)
🔥

រមេរៀនទី ២: ច្បាប់ទី១នៃទែម៉ូឌីណាមិច

សមីការឧស្ម័នឥតប្រែប្រួល (រវាងពីរដំណាក់កាល)
P₁V₁/T₁ = P₂V₂/T₂
ការងារ
W = 0
(អ៊ីសូកូរី - V ថេរ)
W = PΔV
(អ៊ីសូបារី - P ថេរ)
W = nRT ln(V₂/V₁)
(អ៊ីសូទែម៉ល - T ថេរ)
W = ∫PdV
(សម្ពាធផ្លាស់ប្តូរ)
ថាមពលខាងក្នុង
U = (3/2)nRT
(សម្រាប់ឧស្ម័នម៉ូណូអាតូមិច)
ΔU = (3/2)nRΔT
ច្បាប់ទី១នៃទែម៉ូឌីណាមិច
Q = W + ΔU
សញ្ញា:
• Q > 0: ទទួលកំដៅ
• Q < 0: ផ្តល់កំដៅ
• W > 0: ឧស្ម័នធ្វើការងារ
• W < 0: ការងារធ្វើលើឧស្ម័ន
• ΔU > 0: ថាមពលកើន
• ΔU < 0: ថាមពលថយ
ដំណើរការពិសេស
Q = 0
(អាដ្យាបាទិច)
ΔU = 0
(ស៊ីក្លិក - ត្រលប់ទៅដំណាក់កាលដើម)
🚗

រមេរៀនទី ៣: ម៉ាស៊ីនកំដៅ

ម៉ាស៊ីនកាណូត (ឥតប្រែប្រួល)
W = Q_H - Q_C = Pt
(ការងារដែលធ្វើ)
e = 1 - T_C/T_H
(ប្រសិទ្ធភាពទ្រឹស្ដី)
e = W/Q_H
(ប្រសិទ្ធភាពពិត)
ម៉ាស៊ីន ៤-ដំណាក់កាល (អូតូ/ឌីសែល)
ដំណាក់កាលទី១: ចូល (Intake)
ដំណាក់កាលទី២: សង្កត់ (Compression)
ដំណាក់កាលទី៣: ថាមពល (Power) - ផលិតការងារ
ដំណាក់កាលទី៤: ចេញ (Exhaust)
ប្រសិទ្ធភាព
e_th = W/Q_H
(កំដៅ)
e_m = W_out/W_in
(មេកានិច)
e_total = e_th × e_m
(សរុប)
🌊

រមេរៀនទី ៤: គោលការណ៍នៃការបន្ថែមរលក

រំញ័រ
y = a sin(ωt + φ)
ការបន្ថែមរលក
y = y₁ + y₂ = A sin(ωt + Φ)
A² = a₁² + a₂² + 2a₁a₂cos(φ₂ - φ₁)
(អំព្លីទុតផល)
tanΦ = (a₁sinφ₁ + a₂sinφ₂)/(a₁cosφ₁ + a₂cosφ₂)
(ផាសដំបូង)
រលកនៅចម្ងាយ d
y = a sin(ωt - kd)
ការជ្រៀតជ្រែក
x = nλ
(សំណង់ - constructive)
x = (n - 1/2)λ
(បំផ្លាញ - destructive)
សមីការរលកទូទៅ
y = a sin(kx - ωt)
λ = ប្រវែងរលក
k = 2π/λ (លេខរលក)
v = λf = ω/k (ល្បឿនរលក)
ω = 2πf (ភាពញឹកញាប់មុំ)
រលកឈរ
y = 2a sin(kx) cos(ωt)
x = nλ/2
(ចំណុចណូត - nodes)
x = (n - 1/2)λ/2
(ចំណុចអង់ទីណូត - antinodes)
• ចំនួនពាក់កណ្តាលប្រវែងរលក = n
• ចំនួនអង់ទីណូត = n
• ចំនួនណូត = n + 1
• ចំនួនរង្វង់ = n
💫

រមេរៀនទី ៥: ការជ្រៀតជ្រែក និងឌីប្រាក់ស្យុង

រលកមេកានិច
Δd = d₂ - d₁
(ភាពខុសគ្នាផ្លូវ)
Δd = nλ
(សំណង់ - constructive)
Δd = (n - 1/2)λ
(បំផ្លាញ - destructive)
d₁ + d₂ = S₁S₂
(ផលបូកចម្ងាយ)
រលកសំឡេង
Δd = a sinθ
(ភាពខុសគ្នាផ្លូវ)
f_beat = |f₁ - f₂|
(ភាពញឹកញាប់ប៉ះ)
រលកពន្លឺ
sinθ = nλ/a
(ចន្លោះភ្លឺ - bright fringe)
sinθ = (n - 1/2)λ/a
(ចន្លោះងងឹត - dark fringe)
i = λD/a
(ចម្ងាយចន្លោះ)
x_n = nλD/a
(ទីតាំងចន្លោះភ្លឺ)
x_n = (n - 1/2)λD/a
(ទីតាំងចន្លោះងងឹត)
ឌីប្រាក់ស្យុង (បន្ទះរន្ទះមួយ)
a sinθ = nλ
(ទីតាំងមុំ)
x = nλD/a
(ទីតាំងចន្លោះងងឹត)
🧲

រមេរៀនទី ៦: ដែន និងកម្លាំងម៉ាញេទិច

ដែនម៉ាញេទិច
ខ្សែត្រង់:
B = μ₀I / (2πr)
រង្វង់:
B = μ₀I / (2R)
សូលេណូអ៊ីត:
B = μ₀nI
ដែល n = N/L (ចំនួនវេនក្នុងមួយឯកតាប្រវែង)
កម្លាំងអេឡិចត្រូម៉ាញេទិច
កម្លាំងលើខ្សែ:
F = BIL sinα
ដែល α = មុំរវាង B និង I
កម្លាំងរវាងខ្សែប៉ារ៉ាឡែល:
F = μ₀I₁I₂L / (2πd)
ចលនាផង់ក្នុងដែនឯកសណ្ឋាន
Fₘ = qvB
(កម្លាំងម៉ាញេទិច)
R = mv/(qB)
(កាំនៃគន្លង)
T = 2πm/(qB)
(រយៈពេល)
ω = qB/m
(ភាពញឹកញាប់មុំ)
⚡

រមេរៀនទី ៧: អាំងឌុចស្យុងអេឡិចត្រូម៉ាញេទិច

ភ្លុចម៉ាញេទិច
Φ = BA cosθ
ដែល θ = មុំរវាង B និង A
បម្រែបម្រួលភ្លុច
ΔΦ = BΔA
(នៅពេល B ថេរ)
ΔΦ = AΔB
(នៅពេល A ថេរ)
ΔΦ = Δ(BA cosθ)
(ករណីទូទៅ)
កម្លាំងអគ្គិសនីចលករអាំងថ្មី
E = -N ΔΦ/Δt
(ច្បាប់ផារ៉ាដេ)
E = BvL
(ម៉ូស្យុង - motional EMF)
e = NBAω sin(ωt)
(ហ្សេនេរ៉ាទ័រ - generator)
e_max = NBAω
(កម្លាំងអគ្គិសនីចលករអតិបរមា)
🔌

រមេរៀនទី ៨: អូតូអាំងឌុចស្យុង

អាំងឌុចតង់
L = NΦ/I
កម្លាំងអគ្គិសនីចលករអូតូអាំងខ្ចី
e = -L di/dt
តង់ស្យុងសងខាងបូប៊ីន
V = Ri + L di/dt
សៀគ្វី RL
τ = L/R
(ថេរ័ណ្ដពេលវេលា)
i = (E/R)(1 - e^(-t/τ))
(កំពុងផ្ទុក)
i = (E/R)e^(-t/τ)
(កំពុងរំសាយ)
សៀគ្វីលំរយោល LC
T = 2π√LC
(រយៈពេល)
f = 1/(2π√LC)
(ភាពញឹកញាប់)
Q_max = CV_max
(បន្ទុកអតិបរមា)
សៀគ្វីចរន្តឆ្លាស់ (AC)
i = Iₘ sin(ωt + φ)
(ចរន្តភ្លាម)
Iᵣₘₛ = Iₘ/√2
(RMS current)
Vᵣₘₛ = Vₘ/√2
(RMS voltage)
I_c = CωV
(ចរន្តកុងដង់)
I_L = V_L/(Lω)
(ចរន្តអាំងឌុច)
tanφ = (I_L - I_C)/I_R
(មុំផាស)
សៀគ្វី RLC ស៊េរី
Z = √(R² + (Lω - 1/(Cω))²)
(អាំបេដង់)
Iᵣₘₛ = Vᵣₘₛ/Z
V_R = IᵣₘₛR
V_C = Iᵣₘₛ/(Cω)
V_L = IᵣₘₛLω
tanφ = (V_L - V_C)/V_R
សៀគ្វីរវរសូណង់
Lω = 1/(Cω)
(លក្ខខណ្ឌរវរសូណង់)
f = 1/(2π√LC)
(ភាពញឹកញាប់រវរសូណង់)
Z = R
(នៅរវរសូណង់)
ត្រង់ស្ទទាំងរ (Transformer)
V₂/V₁ = N₂/N₁
(តង់ស្យុង)
I₁/I₂ = N₂/N₁
(ចរន្ត)
P₁ = P₂
(ឥតបាត់បង់)
η = P₂/P₁ × 100%
(ប្រសិទ្ធភាព)
ប្រភេទ:
• Step-down: V₂ < V₁, N₂ < N₁
• Step-up: V₂ > V₁, N₂ > N₁
