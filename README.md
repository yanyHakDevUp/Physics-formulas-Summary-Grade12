កម្មវិធីវែបសម្រាប់ឯកសារយោងរូបមន្តរូបវិទ្យាពេញលេញ និងអន្តរកម្ម ដែលត្រូវបានរចនាឡើងសម្រាប់សិស្សថ្នាក់ទី១២។ ឧបករណ៍អប់រំនេះមានរូបមន្តរូបវិទ្យាសំខាន់ៗទាំងអស់ដែលត្រូវបានរៀបចំតាមមេរៀន ជាមួយនឹងការគាំទ្រភាសាខ្មែរពេញលេញ។ កម្មវិធីនេះមានប្រព័ន្ធតម្រងមេរៀនដ៏មានឥទ្ធិពល ដែលធ្វើឱ្យសិស្សងាយស្រួលក្នុងការផ្តោតលើប្រធានបទជាក់លាក់កំឡុងពេលសិក្សា និងការរៀបចំប្រឡង។
